# Copiloto WIN Live — Simulador

Simulador mobile-first do projeto Renda Extra DT.

- Feed sintético de WIN no navegador
- VWAP, delta/agressão, book imbalance e volatilidade
- Estados: COMPRA CONFIRMADA, VENDA CONFIRMADA, AGUARDAR, SEM TRADE e PREGÃO ENCERRADO
- 1 WIN, meta +R$60 e stop -R$40
- MAE/MFE, overtrade e alertas de disciplina
- Janela operacional principal 10h15–11h30

**Importante:** esta versão não conecta à B3, corretora ou ProfitDLL. É um laboratório de simulação.
